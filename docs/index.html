매일의 건강을 기록하는 가장 편안하고 안전한 습관

검사결과·바이탈·식단·일정까지 — 홈을 내 목적에 맞게 구성하고, 민감한 기록은 온전히 내 기기에 암호화되어 보관됩니다.

  • 맞춤 홈
  • 건강 목표
  • 기간 비교 추이
  • OCR 검사결과
  • 온디바이스
  • Face ID 잠금

무엇을 할 수 있나요

치료·회복 중에도, 일상 건강 관리에도. 바램은 기록을 한곳에 모으고 민감한 데이터는 기기 밖으로 보내지 않습니다.

  • 맞춤 홈 화면

    치료·건강·보호자 목적에 맞춰 시작하고, 홈에 보일 항목을 켜고 끄며 순서까지 바꿀 수 있습니다.

  • 검사결과 OCR

    결과지를 촬영하거나 앨범에서 고르면, 기기 안에서 글자를 인식한 뒤 직접 검토·저장합니다.

  • 바이탈·기간 비교

    혈압·혈당·체온·체중을 남기고, 7일·30일 추이와 직전 기간 비교로 변화를 파악합니다.

  • 건강 목표

    목표 체중·혈당을 정해 두면 오늘 기록과 비교해 보여 줍니다. 치료 차수도 홈에서 바로 수정할 수 있습니다.

  • 자연어 식단

    평소 말하듯 식사를 적으면 칼로리·단백질 참고값을 계산합니다. (선택 시 공공 식품 DB)

  • 일정·로컬 알림

    항암·외래·채혈 일정을 관리하고, 원하면 기기 캘린더와 일정 미리 알림을 사용합니다.

  • PDF·백업

    로컬 PDF 리포트와 데이터 백업·삭제를 기기 안에서 처리합니다. 서버 업로드 없음.

  • 잠금·프라이버시

    Face ID·지문·기기 암호 잠금과 앱 전환 시 화면 가림으로 민감한 기록을 지킵니다.

실제 화면으로 보는 바램의 주요 흐름입니다.

홈

오늘 해야 할 건강 기록이 한눈에

케어 목적에 맞는 홈으로 시작하고, 보고 싶은 블록만 골라 순서를 바꿉니다. 목표 대비 체중·혈당과 미니 추이까지 한 화면에서 확인합니다.

  • 홈 항목 표시·순서 직접 편집
  • 건강 목표와 오늘 기록 비교
  • 치료 진행·항암 차수 빠른 수정
  • 보호자 모드로 가족 기록도 정리 가능

검사 · 랩

수치를 저장하고, 정상 구간과 함께 추이 확인

ANC, WBC, Hb, PLT, 간·신장 수치 등을 기록하고 차트에서 변화를 봅니다. 결과지 OCR로 입력 부담을 줄입니다.

  • 기기 안 OCR → 사용자가 검토 후 저장
  • 랩 목록과 항목별 추이 차트
  • 의료진 상담 시 보여주기 쉬운 화면 구성

바이탈

추이를 보고, 이전 기간과 비교

측정값을 남기면 추이 그래프로 이어집니다. 최근 7일·30일을 고르고 직전 기간과 겹쳐 보며 평균 변화까지 확인합니다.

  • 혈압·혈당·체온·체중·걸음 추이
  • 7일 / 30일 / 전체 기간 선택
  • 이전 기간 비교와 평균 변화 요약

투데이

컨디션·식단을 빠르게

체온·체중·수분·증상·식사를 큰 터치로 남깁니다. 식단은 자연어로 적고, 칼로리·단백질 목표는 참고용으로 둡니다.

  • 하루 컨디션을 빠르게 체크
  • 자연어 식단 기록과 메뉴 매칭 개선
  • Apple Health·Health Connect 걸음·활동(선택)

일정

항암·외래·채혈 일정을 놓치지 않게

치료·진료 일정을 앱에서 관리하고, 필요하면 기기 캘린더와 로컬 미리 알림을 켭니다. 서버 푸시 없이 기기에서만 알려 드립니다.

  • 치료·외래·채혈 일정 관리
  • 기기 캘린더 연동(선택)
  • 일정 1시간 전 로컬 알림(선택)

내 정보

프로필·목표·잠금·내보내기를 한곳에서

케어 경로·건강 목표·보안·백업을 프로필에서 다룹니다. 계정 로그인 없이 기기 안의 기록만 사용합니다.

  • 건강 목표·치료 경로 설정
  • Face ID / 생체 / 기기 암호 잠금
  • 로컬 PDF·백업·데이터 삭제

데이터 보안

광고·마케팅을 위한 건강 데이터 판매·공유는 하지 않습니다. 원칙은 온디바이스입니다.

  • Local-First

    건강 기록은 기본적으로 사용자 기기 안에서만 처리됩니다. 운영자 서버로 축적하지 않습니다.

  • 온디바이스 암호화

    로컬 DB와 OS 키체인/키스토어를 활용합니다. 광고·마케팅용 판매·공유를 하지 않습니다.

  • 계정 로그인 없음

    회원 가입 없이 바로 기록합니다. 식단용 공공 식품 DB만 기능을 켤 때 선택적으로 내려받습니다.

  • 의료기기 아님

    진단·처방·치료를 대체하지 않습니다. 수치·영양 해석은 참고용이며 의료진과 상의하세요.
