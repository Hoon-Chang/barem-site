주요 기능

핵심 기능을 탭으로 체험하세요

검사 OCR, 발열 가이드, 진료 브리핑, 가족 연동 — 네 가지를 고른 뒤, 아래에서 실제 화면까지 이어서 보세요.

기능 체험

캡처 한 장이면 수치·그래프까지

병원 앱·종이 결과지를 찍으면 기기 안에서 OCR이 수치를 읽고, 정상 범위 밴드와 함께 추이를 보여 줍니다.

  • 기기 안 OCR
  • 정상 범위 밴드
  • 차수·기간 비교
  1. 1

    결과지·캡처 한 장으로 입력 부담을 줄입니다

  2. 2

    ANC·WBC·Hb·PLT 등 핵심 수치를 정상 구간과 함께 봅니다

  3. 3

    7일·30일·차수별 비교로 외래 전 변화를 미리 정리합니다

함께 쓰는 기능

일상 기록까지 같은 앱에서

핵심 네 가지 외에, 오늘 미션·간편사용·복약·잠금도 이어서 쓸 수 있습니다.

  • 오늘 미션

    오늘 챙길 한 가지를 홈에서 바로 안내합니다. 식사는 아침·점심·저녁을 모두 남겨야 완료로 표시됩니다.

  • 간편사용

    오늘·약·더보기 세 탭과 큰 글씨로, 기력이 없을 때도 기록만 먼저 남길 수 있습니다.

  • 복약 알림

    약 이름과 시각만 넣으면 알려 드리고, 「먹었어요」로 확인합니다. 가족 연동 시 미복용은 수치 없이 알려 드립니다.

  • 차수별 비교

    항암 차수를 골라 검사·체중·식사를 나란히 비교하고, 상담 참고용으로 모아 둡니다.

  • 자연어 식단

    평소 말하듯 식사를 적으면 칼로리·단백질 참고값을 계산합니다.

  • 잠금·프라이버시

    Face ID·지문·기기 암호 잠금과 앱 전환 시 화면 가림으로 민감한 기록을 지킵니다.

앱 둘러보기

실제 화면으로 이어서 보기

홈·가족 연동·간편사용·복약·검사·기록·일정까지 흐름을 따라가 보세요.

홈

오늘 해야 할 건강 기록이 한눈에

케어 목적에 맞는 홈으로 시작하고, 오늘 미션·빠른 기록 타일로 남길 것만 먼저 챙깁니다. 보고 싶은 블록은 켜고 끄며 순서를 바꾸고, 목표 대비 체중·혈당과 미니 추이까지 한 화면에서 확인합니다.

  • 오늘 미션으로 지금 남길 한 가지 안내
  • 홈 항목 표시·순서 직접 편집
  • 케어 목적에 맞춘 기본 홈 구성
  • 건강 목표와 오늘 기록 비교·미니 추이
  • 치료 진행·항암 차수 빠른 수정
  • 홈 위에서 「나」와 연동 가족 바로 전환

가족 안심 연동

암호화해 보내고, 보호자 기기에서만 읽기

원하는 가족과만 QR로 연결합니다. 환자 기기에서 남긴 기록은 암호화되어 보호자 기기로만 전달되고, 서버에는 수치·평문을 남기지 않습니다. 보호자는 읽기 전용으로 오늘을 함께 봅니다.

  • QR 페어링 · 환자→보호자 단방향
  • 암호문 중계 후 전달용 사본 삭제
  • 홈에서 가족 프로필 전환·읽기 전용
  • 알림에 이름·기록 종류만 · 수치 미포함
  • 연동 해제 후에도 받은 기록은 직접 지울 때까지 유지

간편사용

오늘·약·더보기로 단순하게

간편사용을 켜면 하단이 오늘·약·더보기 세 탭으로 바뀌고 글씨·버튼이 커집니다. 시스템 글씨가 크면 안내를 보여 드리며, 필요할 때 일반 화면으로 돌아올 수 있습니다.

  • 오늘 탭에서 미션·체온·체중·혈압·혈당·식사
  • 약 탭에서 「먹었어요」로 복용 확인
  • 더보기에서 검사·일정·설정 진입
  • 일반 화면으로 언제든 전환

복약

정해진 시각에 「먹었어요」까지

약 이름과 시각만 넣으면 한국 시간 기준으로 알려 드립니다. 홈·알림·간편사용 「약」에서 복용을 확인하고, 「먹었어요」를 누를 때까지 다시 알려 드립니다.

  • 정시 복약 알림(한국 시간)
  • 홈·알림에서 바로 복용 확인
  • 간편사용 「약」 탭의 큰 「먹었어요」
  • 가족 연동 시 미복용은 수치 없이 보호자 알림

검사 · 랩

수치를 저장하고, 정상 구간과 함께 추이·기간 비교

ANC, WBC, Hb, PLT, 간·신장 수치 등을 기록하고 차트에서 변화를 봅니다. 케어 목적에 맞춰 검사 칩 색·짧은 이름으로 읽고, 탭해 항목을 걸러 볼 수 있어요. 7일·30일을 골라 직전 기간과 겹쳐 비교하고, 결과지 OCR로 입력 부담을 줄입니다.

  • 기기 안 OCR → 사용자가 검토 후 저장
  • 랩 목록과 항목별 추이 차트
  • 케어 목적별 칩 색·짧은 이름·탭 필터
  • 7일·30일 이전 기간 비교와 평균 변화
  • 의료진 상담 시 보여주기 쉬운 화면 구성

바이탈

추이를 보고, 이전 기간과 비교

측정값을 남기면 추이 그래프로 이어집니다. 최근 7일·30일을 고르고 「이전 기간과 비교」로 직전 구간을 점선으로 겹쳐 보며, 평균 변화까지 확인합니다.

  • 혈압·혈당·체온·체중·걸음 추이
  • 7일 / 30일 / 전체 기간 선택
  • 이전 기간 비교(점선 오버레이)와 평균 변화 요약

차수별 비교

항암 차수를 골라 수치·체중·식사를 나란히

투여일을 기준으로 차수 구간을 나누고, 비교할 차수를 직접 고릅니다. 검사·체중·칼로리·단백질 추이를 겹쳐 보고, 같은 구간에 함께 변한 기록만 상담 참고용으로 모아 둡니다. 원인 진단이 아닙니다.

  • 차수 A·B 선택 비교
  • 투여일(D0) 기준 체중·식사 오버레이
  • 검사·컨디션 동시 변화 단서(참고용)
  • 케어 리포트에도 차수 흐름 반영

케어 리포트

외래 전, 재택 기록을 네 가지 관점으로

홈의 케어 리포트에서 진료 브리핑·회복 타임라인·누적 독성·영양 방어를 한곳에서 봅니다. 다음 항암·외래가 다가오면 진료 브리핑으로 발열·체중·질문을 먼저 모으고, 필요하면 차수 흐름과 영양까지 이어서 확인합니다. 진단이 아닙니다.

  • 진료 브리핑 — 발열·체중·의료진 질문 한 페이지
  • 회복 타임라인 — 투여일(D0) 기준 차수 흐름
  • 누적 독성 — 차수별 당일 피검사 추이
  • 영양 방어 — 칼로리·단백질·알부민 참고
  • 홈·내 정보에서 바로 진입

기록

컨디션·식단을 빠르게

홈 미션과 중앙 [기록]에서 체온·체중·수분·증상·식사를 남깁니다. 식단은 자연어로 적으면 칼로리·단백질이 분석되고, 목표는 참고용으로 둡니다.

  • 하루 컨디션을 빠르게 체크
  • 자연어 식단 기록과 영양 분석
  • Apple Health·Health Connect 걸음·활동(선택)

일정

항암·외래·채혈 일정을 놓치지 않게

치료·진료 일정을 앱에서 관리하고, 필요하면 기기 캘린더와 로컬 미리 알림을 켭니다. 일정 알림은 기기에서만 울리며, 가족 연동 알림과는 별개입니다.

  • 치료·외래·채혈 일정 관리
  • 진료 예약 전표 OCR(선택)
  • 기기 캘린더 연동·로컬 미리 알림(선택)

내 정보

가족 연동·목표·잠금·내보내기를 한곳에서

케어 경로·건강 목표·가족 안심 연동·보안·백업을 프로필에서 다룹니다. 계정 로그인 없이 기본 기록은 기기 안에만 둡니다.

  • 가족 안심 연동(QR)·과거 기록 다시 보내기
  • 건강 목표·치료 경로·간편사용 설정
  • Face ID / 생체 / 기기 암호 잠금
  • 로컬 PDF·백업·데이터 삭제
