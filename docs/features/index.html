무엇을 할 수 있나요

설치 후에 쓰는 기능들입니다. 필요한 것만 보면 됩니다.

  • 맞춤 홈 화면

    치료·건강·보호자 목적에 맞춰 시작하고, 홈에 보일 항목을 켜고 끄며 순서까지 바꿀 수 있습니다.

  • 손쉬움 화면

    큰 글씨·큰 버튼으로 오늘 기록만 단순하게. 어르신·큰 시스템 글씨에도 쓰기 편하고, 필요할 때 안내도 보여 드립니다.

  • 차수별 비교

    항암 차수를 골라 검사·체중·식사를 나란히 비교합니다. 투여일 기준 추이와 동시 변화 단서를 상담 참고용으로 모읍니다.

  • 검사결과 OCR

    결과지를 촬영하거나 앨범에서 고르면, 기기 안에서 글자를 인식한 뒤 직접 검토·저장합니다.

  • 바이탈·기간 비교

    혈압·혈당·체온·체중을 남기고, 7일·30일 추이와 직전 기간 비교로 변화를 파악합니다.

  • 건강 목표

    목표 체중·혈당을 정해 두면 오늘 기록과 비교해 보여 줍니다. 치료 차수도 홈에서 바로 수정할 수 있습니다.

  • 자연어 식단

    평소 말하듯 식사를 적으면 칼로리·단백질 참고값을 계산합니다. (선택 시 공공 식품 DB)

  • 일정·로컬 알림

    항암·외래·채혈 일정을 관리하고, 원하면 기기 캘린더와 일정 미리 알림을 사용합니다.

  • PDF·백업

    로컬 PDF 리포트와 데이터 백업·삭제를 기기 안에서 처리합니다. 서버 업로드 없음.

  • 잠금·프라이버시

    Face ID·지문·기기 암호 잠금과 앱 전환 시 화면 가림으로 민감한 기록을 지킵니다.
