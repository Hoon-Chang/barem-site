시나리오

항암 3주 주기 환자 활용 예시

투여일부터 외래까지, 오늘 필요한 기록만 순서대로 남기면 됩니다.

  1. D0 · 항암 투여일

    1차수 등록 · 일정 자동 세팅

    항암 차수와 투여일을 등록하면 캘린더에 일정이 잡히고, 홈에서 다음 항암·외래를 바로 확인할 수 있습니다.

  2. D+3 · 부작용 피크

    2원터치 바이탈 · 부작용 칩

    체온·체중을 빠르게 남기고 증상 칩을 선택합니다. 37.8℃ 이상이면 안심 가이드를 바로 보여 드립니다.

  3. D+7 · 회복기

    3식사·걸음으로 회복 흐름

    칼로리·단백질 섭취와 일일 걸음을 남겨 두면, 차수별 회복을 나중에 나란히 볼 수 있습니다.

  4. D+21 · 외래 진료일

    4피검사 OCR + 진료 브리핑

    결과지 캡처로 수치를 넣고, A4 1장 진료 브리핑 리포트로 발열·체중·질문을 정리해 상담에 가져갑니다.
